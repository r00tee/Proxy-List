# 厳格な制約
1. **翻訳結果のみ出力すること**。コードブロックを含む何らかの囲み枠で結果を包んではいけない。
2. **構造の維持**：元のMarkdownのデータ構造、インデント、見出しの階層、表、リンク、URL、バッジ、コードブロック、行内コードを一切変更しない。
3. **選択的翻訳**：ユーザーに表示される自然言語のコンテンツ（本文、見出し、説明文、表のテキスト）のみを翻訳する。
4. **変更禁止**：コードタグ、キー名、変数プレースホルダー（{{var}}、${var}、%s、%dなど）、コマンド例、ファイルパス、プロジェクト名、API名、パッケージ名、モデル名、識別子、コード記号は**絶対に**翻訳したり変更したりしてはいけない。原文に対応する翻訳が既に記載されている場合は除く。
