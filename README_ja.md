このリポジトリでは、**3時間ごとに更新**される**自動化されたプロキシリスト**を提供しており、**HTTP**、**HTTPS**、**SOCKS4**、**SOCKS5**プロキシが含まれています。これらのプロキシは世界中のさまざまな出所から収集されているため、**多様で包括的な**コレクションが実現されています。

## 🌟 主な機能:
- 🔄 **定期的な更新**: 最新のプロキシ情報を提供するため、プロキシリストは**3時間ごとに更新**されます。
- 🌐 **複数のプロトコル対応**: **HTTP**、**HTTPS**、**SOCKS4**、**SOCKS5**プロトコルに対応したプロキシが含まれています。
- 🌍 **国別のプロキシ**: アクセスやフィルタリングを容易にするため、国別に整理されています。
- 🌎 **世界的なカバレッジ**: 様々な用途に対応できる、世界各国のプロキシが用意されています。

## 📂 プロキシファイル:

プロキシリストには直接アクセスできます：
- 🌐 [**HTTPプロキシ**](https://github.com/SoliSpirit/proxy-list/blob/main/http.txt)
- 🔒 [**HTTPSプロキシ**](https://github.com/SoliSpirit/proxy-list/blob/main/https.txt)
- 🛡️ [**SOCKS4プロキシ**](https://github.com/SoliSpirit/proxy-list/blob/main/socks4.txt)
- 🔑 [**SOCKS5プロキシ**](https://github.com/SoliSpirit/proxy-list/blob/main/socks5.txt)

**国別に分類されたプロキシ**については、[**Countries**](https://github.com/SoliSpirit/proxy-list/tree/main/Countries)ディレクトリをご覧ください。
